# Game_JoinPoints_ExpoJove_Bancaja

Flash (2006/2007) join-the-dots game built for the Bancaja ExpoJove youth
fair, by Mediterrania Multimedia. The player connects a sequence of numbered
points to complete a drawing. `licencia.txt` holds an era #id placeholder
(not real data); `progreso/` keeps the intermediate FLA iterations
(`Unir00.fla`, `Unir01.fla`). An example with the same skeleton survives in
the sibling folder `Ejemplo_LicenciaWeb` (excluded from this repository).

> **This project is shared ONLY for educational purposes. Its use, direct or derived, for professional or economic purposes is not permitted.**

For security/integrity reasons, no part of the project needed to be edited or removed: everything is kept as it was left in 2006/2007, including the `licencia.txt` data as-is.

## Requirements / How to run

- Open `Unir.swf` in a Flash Player 8 era runtime (standalone or browser with
  the Flash plug-in), or open `Unir.fla` in Flash 8 / CS to edit the game.
